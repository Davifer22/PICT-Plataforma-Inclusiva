Aprendo a crear documentos

En este curso aprenderás a crear, escribir, modificar y guardar documentos en el computador.

Lección 1. ¿Qué es un documento?

Un documento es un archivo que permite escribir y organizar información, como textos, tareas, cartas o trabajos.

Lección 2. ¿Cómo crear un documento?

Para crear un documento puedes abrir un programa de escritura, como Microsoft Word o LibreOffice Writer. Después selecciona la opción de documento en blanco.

Lección 3. Escribir y modificar texto

Utiliza el teclado para escribir. Si necesitas corregir una palabra, puedes utilizar las teclas de borrar. También puedes seleccionar una parte del texto para modificarla.

Lección 4. Cambiar el tamaño de la letra

Puedes seleccionar el texto y cambiar el tamaño de la letra para facilitar su lectura. También puedes utilizar negrita para destacar palabras importantes.

Lección 5. ¿Cómo guardar un documento?

Para guardar tu trabajo, selecciona la opción Guardar. Elige una carpeta, escribe un nombre para el archivo y confirma la operación.

Lección 6. Abrir un documento guardado

Para consultar un documento que guardaste anteriormente, abre el programa de escritura, selecciona Abrir y busca el archivo en la carpeta donde lo guardaste.
