Aprendo a usar el computador

Aprende a utilizar las funciones básicas del computador para realizar actividades cotidianas.

Nivel: Inicial

Lección 1. Conozco el escritorio del computador

El escritorio es la pantalla principal que aparece cuando iniciamos el computador.

En el escritorio podemos encontrar:

  • Iconos: pequeños símbolos que representan programas, carpetas o archivos.
  • Barra de tareas: muestra programas abiertos y accesos a algunas funciones.
  • Menú de inicio: permite encontrar aplicaciones y opciones del sistema.
  • Papelera de reciclaje: permite encontrar archivos que hemos eliminado.

Lección 2. ¿Qué son los programas?

Los programas son herramientas que permiten realizar diferentes actividades en el computador.

Algunos ejemplos son:

  • Un navegador para visitar páginas de Internet.
  • Un procesador de texto para escribir documentos.
  • Una calculadora para realizar operaciones matemáticas.
  • Un reproductor multimedia para escuchar audio y ver videos.

Lección 3. ¿Cómo abrir y cerrar un programa?

Para abrir un programa

  1. Busca el icono del programa en el escritorio o en el menú de inicio.
  2. Haz doble clic sobre el icono o selecciónalo desde el menú.
  3. Espera a que el programa se abra.

Para cerrar un programa

  1. Busca el botón de cerrar, generalmente identificado con una X.
  2. Presiona el botón.
  3. Si aparece una pregunta para guardar cambios, revisa antes de confirmar.

Lección 4. Aprendo a organizar archivos y carpetas

Los archivos contienen información, como textos, imágenes, documentos o videos.

Las carpetas permiten organizar los archivos para encontrarlos más fácilmente.

Crear una carpeta

  1. Abre el explorador de archivos.
  2. Busca el lugar donde quieres guardar la carpeta.
  3. Selecciona la opción para crear una carpeta nueva.
  4. Escribe un nombre fácil de reconocer.
  5. Presiona Enter.

Lección 5. Aprendo a guardar mis archivos

Guardar un archivo permite conservar la información que hemos creado.

  1. Abre el programa que estás utilizando.
  2. Busca la opción Guardar.
  3. Escribe un nombre para el archivo.
  4. Selecciona la carpeta donde deseas guardarlo.
  5. Presiona Guardar.

También puedes utilizar el atajo de teclado Ctrl + S en muchos programas.

Lección 6. Uso el computador de manera ordenada

Para mantener organizado nuestro computador podemos:

  • Crear carpetas con nombres fáciles de identificar.
  • Guardar los documentos en el lugar correspondiente.
  • Evitar acumular archivos innecesarios.
  • Revisar los archivos antes de eliminarlos.
  • Apagar correctamente el equipo al terminar.
